# Web Scraper

> 이 파일은 **Gemini CLI** 컨텍스트 파일입니다. 이 프로젝트 폴더에서 `gemini`를 실행하면 자동으로 로드됩니다. (Claude Code용 `.claude/` 구성과 동일한 하네스)

웹 스크래핑 시스템의 대상분석→크롤러설계→파싱→저장→모니터링을 에이전트 팀이 협업하여 구축하는 하네스.

## 에이전트 구성

- **crawler-developer** — 크롤러 개발자
- **data-manager** — 데이터 관리자
- **monitor-operator** — 모니터링 운영자
- **parser-engineer** — 파싱 엔지니어
- **target-analyst** — 대상 사이트 분석가

## 워크플로우 (실행 순서)

| 순서 | 담당 | 의존 |
|------|------|------|
| 1 | target-analyst | 없음 |
| 2a | crawler-developer | target-analyst |
| 3a | parser-engineer | target-analyst |
| 4 | data-manager | parser-engineer |
| 5 | monitor-operator | crawler-developer, parser-engineer |
