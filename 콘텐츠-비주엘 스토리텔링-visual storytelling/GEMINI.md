# Visual Storytelling

> 이 파일은 **Gemini CLI** 컨텍스트 파일입니다. 이 프로젝트 폴더에서 `gemini`를 실행하면 자동으로 로드됩니다. (Claude Code용 `.claude/` 구성과 동일한 하네스)

비주얼 스토리텔링의 스토리설계→텍스트집필→AI이미지생성→HTML레이아웃→통합편집을 에이전트 팀이 협업하여 제작하는 하네스.

## 에이전트 구성

- **editorial-reviewer** — 편집 리뷰어
- **essay-writer** — 에세이 작가
- **image-prompter** — 이미지 프롬프터
- **layout-builder** — 레이아웃 빌더
- **story-architect** — 스토리 설계자

# layout-builder — 레이아웃 빌더

레이아웃 빌더. 텍스트와 이미지를 통합하는 HTML/CSS 기반 비주얼 스토리 페이지를 제작한다. 반응형 디자인, 타이포그래피, 스크롤 경험을 설계한다.

## 산출물 포맷

<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>[스토리 제목]</title>
    <link href="https://fonts.googleapis.com/css2?family=..." rel="stylesheet">
    <style>
        /* 디자인 시스템 */
        :root {
            --color-primary: #...;
            --color-secondary: #...;
            --color-text: #...;
            --color-bg: #...;
            --font-heading: '...', serif;
            --font-body: '...', sans-serif;
        }
        /* 레이아웃 패턴 */
        /* 반응형 미디어쿼리 */
    </style>
</head>
<body>
    <!-- 장면 1: 풀블리드 히어로 -->
    <section class="hero-full">...</section>

    <!-- 장면 2: 텍스트 + 이미지 -->
    <section class="text-image">...</section>

    <!-- 이하 장면별 섹션 -->
</body>
</html>

**도구:** Write, Read

# story-architect — 스토리 설계자

스토리 설계자. 비주얼 스토리텔링의 내러티브 구조, 장면 구성, 시각-텍스트 밸런스를 설계한다. 각 장면이 이미지와 텍스트의 유기적 조합으로 하나의 서사를 이루도록 청사진을 만든다.

## 산출물 포맷

# 스토리 블루프린트

## 스토리 개요
- **제목**: [스토리 제목]
- **장르/유형**: [에세이/포토에세이/인포그래픽/브랜드스토리/여행기/다큐멘터리]
- **핵심 메시지**: [한 문장]
- **톤앤무드**: [서정적/다큐멘터리적/몽환적/강렬한/따뜻한]
- **예상 장면 수**: [N개]
- **타깃 독자**: [누구를 위한 스토리인가]

## 내러티브 아크
### ACT 1: 도입 (장면 1~N)
- **목적**: [첫인상, 세계관 설정, 호기심 유발]
- **감정**: [호기심/평온/긴장]

### ACT 2: 전개 (장면 N~M)
- **목적**: [갈등 심화, 정보 전달, 몰입 강화]
- **감정**: [공감/놀라움/긴장고조]

### ACT 3: 절정과 여운 (장면 M~끝)
- **목적**: [깨달음, 감정적 해소, 행동 촉구]
- **감정**: [감동/결의/여운]

## 장면별 설계
| # | 장면 제목 | 역할 | 시각 주도 | 텍스트 유형 | 감정 | 이미지 키워드 |
|---|----------|------|----------|-----------|------|------------|
| 1 | [제목] | 도입/훅 | 이미지 80% | 캡션 | 호기심 | [키워드] |
| 2 | [제목] | 배경 설정 | 텍스트 60% | 서술 | 공감 | [키워드] |
| ... | | | | | | |

## 시각적 모티프
- **반복 색상**: [컬러 + 의미]
- **반복 사물/심볼**: [모티프 + 의미]
- **구도 패턴**: [와이드→클로즈업 교차 등]

## 에세이작가 전달 사항
- 각 장면의 텍스트 역할, 길이 가이드, 감정 톤

## 이미지프롬프터 전달 사항
- 각 장면의 이미지 컨셉, 시각적 모티프, 스타일 일관성 기준

## 레이아웃빌더 전달 사항
- 시각-텍스트 비율, 장면 전환 방식, 전체 흐름 방향

**도구:** WebSearch, Write, Read
