# 데이터 정제 로그

## 정제 전 데이터 요약
- **행 × 열**: 80 × 19 (A계정 원본 데이터)

## 정제 파이프라인

### Step 1: 통계적 유의성(Core Data) 추출
- **탐지 기준**: `조회수 >= 30` 인 메인 트래픽 상품군만 필터링.
- **분리 건수**: 우연한 클릭에 의한 데이터 수십 건 제거.
- **결과**: 스토어 광고비의 대부분을 소진하는 '핵심 모수' 확보.

### Step 2: CVR 0% 악성 트래픽 분리
- **탐지 기준**: 유의미한 트래픽(`조회수 >= 30`)을 받으면서도 `주문수 = 0`인 행 분리.
- **분리 결과 (총 4건 발각)**:
  1. 미미각 마라샹궈 소스 110g 5개 (조회 188)
  2. 일품선간장 1.2L 6개 (조회 58)
  3. 실곤약 말이 1kg 1개 (조회 54)
  4. 비타민C 캔디 200g 5개 (조회 33)

## 정제 후 데이터 요약
- **정보 손실 평가**: 노이즈를 제거하자 A계정의 고질적인 문제(광고비가 4개의 악성 상품에서 줄줄 새고 있음)가 명확하게 드러남. 반면 매출을 견인하는 '굴소스(조회 51, CVR 29%)' 같은 찐캐시카우의 존재도 명확히 분리됨.
