# Code Reviewer

> 이 파일은 **Gemini CLI** 컨텍스트 파일입니다. 이 프로젝트 폴더에서 `gemini`를 실행하면 자동으로 로드됩니다. (Claude Code용 `.claude/` 구성과 동일한 하네스)

코드 리뷰 자동화의 스타일→보안→성능→아키텍처 리뷰를 에이전트 팀이 협업하여 수행하는 하네스.

## 에이전트 구성

- **architecture-reviewer** — 아키텍처 리뷰어
- **performance-analyst** — 코드 성능 분석가
- **review-synthesizer** — 코드 리뷰 종합자
- **security-analyst** — 코드 보안 분석가
- **style-inspector** — 코드 스타일 검사관

## 워크플로우 (실행 순서)

| 순서 | 담당 | 의존 |
|------|------|------|
| 1a | style-inspector | 없음 |
| 2a | security-analyst | 없음 |
| 3a | performance-analyst | 없음 |
| 4a | architecture-reviewer | 없음 |
| 5 | review-synthesizer | style-inspector, architecture-reviewer |
