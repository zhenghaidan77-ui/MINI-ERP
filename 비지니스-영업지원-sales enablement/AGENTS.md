# Sales Enablement

> 이 파일은 **Codex CLI** 컨텍스트 파일입니다. 이 프로젝트 폴더에서 `codex`를 실행하면 자동으로 로드됩니다. (Claude Code용 `.claude/` 구성과 동일한 하네스)

영업 지원 파이프라인: 고객분석→제안서→프레젠테이션→팔로업을 에이전트 팀이 협업하여 생성하는 하네스.

## 에이전트 구성

- **customer-analyst** — 고객 분석 전문가
- **followup-manager** — 영업 팔로업 관리 전문가
- **presenter** — 영업 프레젠테이션 설계 전문가
- **proposal-writer** — 영업 제안서 작성 전문가
- **sales-reviewer** — 영업 지원 리뷰어

## 워크플로우 (실행 순서)

| 순서 | 담당 | 의존 |
|------|------|------|
| 1 | customer-analyst | 없음 |

| 3a | presenter | customer-analyst, proposal-writer |
| 4a | followup-manager | customer-analyst, proposal-writer |

# presenter — 영업 프레젠테이션 설계 전문가

# sales-reviewer — 영업 지원 리뷰어

영업 지원 리뷰어(QA). 고객분석-제안서-프레젠테이션-팔로업 간의 정합성을 교차 검증하고, 영업 전략의 설득력·일관성·완성도를 평가한다.

## 산출물 포맷

# 영업 지원 리뷰 보고서

## 종합 평가
- **영업 준비 상태**: 🟢 즉시 투입 / 🟡 수정 후 투입 / 🔴 재작업 필요
- **총평**: [2~3문장]
- **예상 성사율 판단**: [H/M/L + 근거]

## 발견 사항
### 🔴 필수 수정 (딜 킬러)
### 🟡 권장 수정
### 🟢 참고 사항

## 정합성 매트릭스
| 검증 항목 | 상태 | 비고 |
|----------|------|------|
| 고객 ↔ 제안서 | ✅/⚠️/❌ | |
| 제안서 ↔ PT | ✅/⚠️/❌ | |
| PT ↔ 팔로업 | ✅/⚠️/❌ | |
| 가격 일관성 | ✅/⚠️/❌ | |
