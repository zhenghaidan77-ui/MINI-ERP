# Financial Modeler

> 이 파일은 **Codex CLI** 컨텍스트 파일입니다. 이 프로젝트 폴더에서 `codex`를 실행하면 자동으로 로드됩니다. (Claude Code용 `.claude/` 구성과 동일한 하네스)

수익 모델, 비용 구조, 시나리오 분석, 밸류에이션까지 재무 모델링 전 과정을 에이전트 팀이 협업하여 생성하는 하네스.

## 에이전트 구성

- **cost-analyst** — 비용 구조 분석가
- **model-reviewer** — 재무 모델 리뷰어
- **revenue-modeler** — 수익 모델 설계자
- **scenario-planner** — 재무 시나리오 분석가
- **valuation-expert** — 밸류에이션 전문가

## 워크플로우 (실행 순서)

| 순서 | 담당 | 의존 |
|------|------|------|
| 1a | revenue-modeler | 없음 |
| 2a | cost-analyst | revenue-modeler |
| 3 | scenario-planner | revenue-modeler, cost-analyst |
| 4 | valuation-expert | cost-analyst |
| 5 | model-reviewer | revenue-modeler, scenario-planner |
